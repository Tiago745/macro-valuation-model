Este repositório contém um projeto voltado para a precificação de índices de ações por país e para a construção de uma estratégia sistemática de rotação global (country rotation) baseada em diferenças entre:

Retorno justo estimado por modelos multifatoriais macroeconômicos (APT macro),

Retorno implícito pelo mercado, obtido por métricas de valuation agregadas (ex.: Earnings Yield).

O objetivo é identificar mispricing entre países, gerar sinais de alocação e avaliar o desempenho de uma carteira global construída a partir desses sinais.
